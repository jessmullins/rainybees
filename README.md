# rainybees

**Variable precipitation interacts with land-use change to affect the diversity and composition of native bee assemblages**

Jessica L. Mullins, Keng-Lou James Hung, Joel Gardner, John S. Ascher, David A. Holway | *in review at Ecology*

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.14567890.svg)](https://doi.org/10.5281/zenodo.14567890)

---

## Overview

This repository contains all data and code needed to reproduce the analyses and figures in the manuscript. The study examines how winter precipitation and habitat fragmentation jointly structure bee assemblage diversity, composition, and body size across seven survey years (2011, 2012, 2015, 2016, 2022, 2023, 2024) in coastal sage scrub and chaparral habitats in southwestern San Diego County, California.

We tested four predictions: (1) primary production increases with same-year winter precipitation; (2) bee diversity increases with winter precipitation and is higher in reserves than fragments; (3) precipitation and land-use change alter assemblage composition; and (4) assemblage-weighted mean body size increases with winter precipitation.

Bee occurrence data (23,516 specimens, 202 species) are archived on GBIF: https://doi.org/10.15468/74ktmt

## Data

### Raw data (`data/raw/`)

| File | Description | Source |
|---|---|---|
| `occurrences.csv` | GBIF occurrence records for all bee specimens; columns follow the Darwin Core standard | GBIF (doi:10.15468/74ktmt) |
| `siteInfo.csv` | Study plot locations (`fieldNumber`, `Latitude`, `Longitude`), habitat type (Reserve/Fragment), and area (ha). Read by R-00, R-04, and R-08. | This study |
| `traits.csv` | Species-level traits: mean intertegular distance (ITD, mm), dietary specialization, sociality, and range size. ITD values are species means from field measurements by the authors and collaborators. | This study |
| `precipitation.csv` | Daily precipitation (mm) for Montgomery Field Air Station (GHCN `USC00046646`), the regional precipitation proxy used throughout. Columns: `DATE`, `PRCP`. | Generated by R-00 from NOAA GHCN |
| `site_stations.csv` | Plot-to-station assignments with station names, IDs, coordinates, and great-circle distances to plot centroids. Each plot is matched to its nearest GHCN station within 20 km that has ≤ 5% missing Nov–Mar records in every year 2000–2024. | Generated by R-00 from NOAA GHCN |
| `precip.csv` | Same-year and previous-year winter (Nov–Mar) precipitation totals per plot per year, 2000–2024. | Generated by R-00 from NOAA GHCN |
| `missing.csv` | Percentage of missing daily precipitation records per candidate station per year, with a `flag_too_missing` column, used for the station quality screen. | Generated by R-00 from NOAA GHCN |
| `wild_evi.csv` | MODIS MOD13Q1 EVI (Version 6.1) averaged over the growing season (March–August) for natural wildland vegetation in western San Diego County, 2000–2024. See `gee/evi_extraction.js` for processing code. | Google Earth Engine |
| `all_plants.csv` | Plant species occurrence records by site and survey date (2015, 2016, 2022, 2023, 2024); curated from field surveys and iNaturalist observations. Plants from 2022–2024 are available at https://www.inaturalist.org/projects/sd-fragment-reserve-resurvey. The raw iNaturalist export is not provided; use this file directly for reproducibility. | This study |

The four NOAA-derived files are produced by `R-00_station_setup.R` but are **included in this repository**, so R-00 does not need to be re-run to reproduce the analyses. They live in `data/raw/` rather than `data/cleaned/` because they are inputs to the analysis pipeline proper, which begins at R-01.

## Scripts

**Run all scripts from the repo root** (`rainybees/`) so that relative paths resolve correctly. In RStudio: `setwd("path/to/rainybees")` or open as a project.

**Run R-01 then R-02 before anything else** — all analysis scripts depend on their outputs in `data/cleaned/`. R-00 is a one-time setup script and does not need to be re-run; its outputs are already in `data/raw/`.

| Script | Prediction | Description |
|---|---|---|
| `R-00_station_setup.R` | — | **One-time setup; not required to reproduce the analyses.** Queries the NOAA GHCN station inventory for all California stations with continuous PRCP coverage 2000–2024, computes Haversine distances from every study plot to every station, and retains the two nearest within 20 km. Screens candidate stations for data completeness (any station-year with > 5% missing Nov–Mar days is disqualified) and assigns each plot its nearest surviving station. Downloads daily records for the assigned stations and computes same-year and previous-year winter (Nov–Mar) precipitation totals per plot per year, 2000–2024. Finally downloads and saves the full Montgomery Field daily record, which serves as the regional precipitation proxy in all downstream analyses. Requires network access and the `rnoaa` package (see R environment below). |
| `R-01_data_cleaning.R` | — | Loads GBIF occurrence data; joins site metadata and species traits; harmonizes legacy site codes and species synonyms; calculates trap-day effort; builds the community abundance matrix; runs iNEXT to determine the shared coverage target and generate the coverage-rarefied community matrix. |
| `R-02_precipitation_processing.R` | — | Converts the raw daily precipitation record to annual winter totals (mm) with lags WPy0–WPy0-6 for the Montgomery Field regional proxy. Tests whether precipitation variance is primarily temporal or spatial (two-way ANOVA across all stations). Tests for temporal autocorrelation in the annual record (ACF/PACF). Generates precipitation figures and the station map. |
| `R-03_primary_production.R` | 1 | Linear regression of mean summer EVI on same-year winter precipitation (WPy0) across 25 years (2000–2024). Tests whether primary production tracks interannual precipitation variation. |
| `R-04_floral_richness.R` | 1 (supplement) | Mixed-effects model of floral species richness across five survey years (2015, 2016, 2022, 2023, 2024) as a function of site type × year. Also tests EVI as a predictor of floral richness. Emmeans post-hoc contrasts. |
| `R-05_bee_diversity.R` | 2 | **Main diversity analysis.** Coverage-standardized Hill numbers (q = 0, 1, 2) estimated with `iNEXT::estimateD()` at the shared coverage target from R-01. Mixed-effects models with WPy0, WPy0-1, site type, and their interactions. AIC model comparison; marginal and conditional R² via MuMIn. DHARMa and Box-Cox model diagnostics. |
| `R-06_assemblage_composition.R` | 3 | Hellinger-transformed, effort-normalized RDA with site type, WPy0, and WPy0-1 as predictors. Variance partitioning via partial RDAs. PERMANOVA (adonis2) blocked by plot and by year. Sensitivity analysis with additional precipitation lags. Indicator species analysis (IndVal.g, 1200 permutations) across Reserve/Fragment × Wet/Dry combinations for both same-year and previous-year precipitation windows. Euler diagrams and stacked bar plots of indicator species. |
| `R-07_body_size.R` | 4 | Coverage-standardized abundance-weighted (and presence-weighted) mean ITD as a proxy for assemblage body size. Mixed-effects models with WPy0, WPy0-1, site type, and interactions (main analysis) and without interactions (sensitivity). Type-split models for reserves and fragments separately reported in supplement. DHARMa and Box-Cox model diagnostics. |
| `R-08_spatialAutoCorr.R` | 2 (supplement) | **Tests whether the site-type effect on richness is confounded with spatial position.** Refits the primary richness model with plot and year random effects, extracts site-level random intercepts (BLUPs), and tests them for spatial autocorrelation using Moran's I with inverse great-circle-distance weights. Separately tests whether habitat type is *itself* spatially clustered (Moran's I on Reserve/Fragment coded numerically), which speaks directly to the concern that reserves are aggregated relative to fragments. Adds a spline correlogram of residual correlation against distance, and a GLS robustness check comparing models with and without an exponential spatial correlation structure at the site level. Finally addresses within-type non-independence: a permutation test on reserve–reserve versus fragment–fragment pairwise distances, and a model nesting plots within their named reserve complex (`(1 | Locality/Plot) + (1 | year)`) so that reserve replication is counted at the complex level rather than the plot level. |

### Google Earth Engine

`gee/evi_extraction.js` extracts MODIS MOD13Q1 EVI for natural wildland vegetation in western San Diego County (March–August growing season, 2000–2024) masked to a custom wildlands asset. To run: paste the script into the [GEE Code Editor](https://code.earthengine.google.com/), click **Run**, then go to the Tasks tab and run the export. Save the resulting CSV as `data/raw/wild_evi.csv`.

Wildlands mask asset (public): https://code.earthengine.google.com/?asset=users/jessmullins/Wildlands_mask_sitesBBox

## Model diagnostics

DHARMa simulated residual diagnostics were run for all linear mixed-effects models (R-05 and R-07). For each model, we report: (1) Box-Cox optimal lambda to assess whether transformation is warranted; (2) DHARMa dispersion, outlier, and uniformity tests. All models passed DHARMa tests (p > 0.05), confirming that the Gaussian approximation is acceptable given that diversity and body size values are not concentrated near zero. Full diagnostic plots are saved to `figures/diagnostics/` and summary tables to `results/diagnostics_dharma.xlsx` and `results/diagnostics_dharma_itd.xlsx`.

Type-split body size models (R-07) produce singular random effects fits because splitting by habitat type substantially reduces within-plot replication. Fixed effect estimates remain valid; these results are reported in the supplementary materials.

Spatial non-independence is addressed separately in R-08, whose outputs are written to `results/spatial_autocorrelation_results.rds` and `figures/FigureSX_spatial_correlogram.pdf`.

### A note on site codes

`SWS1` and `SWS1A` are two plot codes at the same physical coordinates and are retained as separate random-effect levels throughout the main analyses, matching `df_analysis`. R-08 merges them for the site-level GLS and Moran's tests, where two rows at zero distance would otherwise break the correlation structure. This is a deliberate simplification confined to the spatial checks.

## R environment

All analyses were run in **R version 4.5.2**. Install the packages needed for R-01 through R-08 with:

```r
install.packages(c(
  "tidyverse", "lubridate", "lme4", "lmerTest", "car", "iNEXT", "vegan",
  "MuMIn", "performance", "indicspecies", "patchwork", "ggeffects",
  "broom", "broom.mixed", "writexl", "forcats", "readxl", "stringr",
  "emmeans", "openxlsx", "influence.ME", "ggpubr", "ggsignif",
  "geosphere", "ggmap", "ggrepel", "RColorBrewer",
  "eulerr", "DHARMa", "MASS", "ggfittext",
  "ape", "ncf", "nlme"
))
```

`R-00_station_setup.R` additionally requires `rnoaa`, which is **no longer available on CRAN**. It can be installed from GitHub:

```r
remotes::install_github("ropensci/rnoaa")
```

Because R-00 is a one-time setup script and its outputs are included in `data/raw/`, reproducing the published analyses does not require installing `rnoaa`.

Key packages and their roles:

| Package | Role |
|---|---|
| `iNEXT` | Coverage-based rarefaction and Hill number estimation |
