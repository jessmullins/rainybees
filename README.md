# rainybees

**Long-term bee assemblage responses to precipitation variability and habitat fragmentation in southern California scrub**

Jessica Mullins et al. | *in preparation for Ecology*

---

## Overview

This repository contains all data and code needed to reproduce the analyses and figures in the manuscript. The study examines how winter precipitation and habitat fragmentation jointly structure bee assemblage diversity, composition, and body size across seven survey years (2011, 2012, 2015, 2016, 2022, 2023, 2024) in coastal sage scrub and chaparral habitats in southwestern San Diego County, California.

We tested four predictions: (1) primary production increases with same-year winter precipitation; (2) bee diversity increases with winter precipitation and is higher in reserves than fragments; (3) precipitation and land-use change alter assemblage composition; and (4) assemblage-weighted mean body size increases with winter precipitation.

Bee occurrence data (23,516 specimens, 202 species) are archived on GBIF: https://doi.org/10.15468/74ktmt

## Data

### Raw data (`data/raw/`)

These are the true inputs to the analysis pipeline — none are derived from other files in this repository.

| File | Description | Source |
|---|---|---|
| `occurrences.csv` | GBIF occurrence records for all bee specimens; columns follow the Darwin Core standard | GBIF (doi:10.15468/74ktmt) |
| `siteInfo.csv` | Study site locations, habitat type (Reserve/Fragment), and area (ha) | This study |
| `traits.csv` | Species-level traits: mean intertegular distance (ITD, mm), dietary specialization, sociality, and range size. ITD values are species means from field measurements by the authors and collaborators. | This study |
| `sd_station_prcp.csv` | Daily precipitation (inches) for all San Diego area NWS stations; columns: STATION, NAME, DATE, PRCP. Downloaded from NOAA Climate Data Online (https://www.ncdc.noaa.gov/cdo-web/). Stations: Montgomery Field, International Airport, El Cajon, SeaWorld, Miramar NAS, Chula Vista. | NOAA CDO |
| `wild_evi.csv` | MODIS MOD13Q1 EVI (Version 6.1) averaged over the growing season (March–August) for natural wildland vegetation in western San Diego County, 2000–2024. See `gee/evi_extraction.js` for processing code. | Google Earth Engine |
| `site_stations.csv` | Plot-to-station assignments with station names, IDs, and distances to plot centroids. Manually compiled from NOAA GHCN station metadata. | NOAA GHCN |
| `precip.csv` | Same-year and previous-year winter precipitation totals per plot per year, 2000–2024. Manually downloaded and compiled from NOAA CDO. | NOAA CDO |
| `missing.csv` | Percentage of missing daily precipitation records per station per year, used for data quality assessment. Manually compiled from NOAA CDO downloads. | NOAA CDO |
| `all_plants.csv` | Plant species occurrence records by site and survey date (2015, 2016, 2022, 2023, 2024); curated from field surveys and iNaturalist observations. Plants from 2022–2024 are available at https://www.inaturalist.org/projects/sd-fragment-reserve-resurvey. The raw iNaturalist export is not provided; use this file directly for reproducibility. | This study |

Generated by running R-01 and R-02 — do not need to be downloaded separately. Documented here for transparency.

| File | Generated by | Description |
|---|---|---|
| `df_analysis.csv` | R-01 | Filtered occurrence records with traits joined, trap effort calculated, and canonical species names added |
| `comm_abun.csv` | R-01 | Site-year × species abundance matrix (full, pre-rarefaction) |
| `comm_rare.csv` | R-01 | Site-year × species abundance matrix rarefied to the shared coverage target |
| `meta.csv` | R-01 | One row per site-year with trap effort, observed coverage, and rarefied sample size |
| `rarefied_n.csv` | R-01 | Per-assemblage rarefied sample size and achieved coverage from iNEXT |
| `target_coverage.rds` | R-01 | Shared iNEXT coverage target scalar (minimum observed coverage across all assemblages). Loaded by R-05, R-07, and R-08 to ensure identical standardization across all analyses. |
| `precipyrs.csv` | R-02 | Annual winter precipitation totals (Nov–Mar, Montgomery Field station) with same-year (WPy0) and lagged values (WPy0-1 through WPy0-6). Centered predictors computed within each analysis script. |

## Scripts

**Run all scripts from the repo root** (`rainybees/`) so that relative paths resolve correctly. In RStudio: `setwd("path/to/rainybees")` or open as a project.

**Run R-01 then R-02 before anything else** — all analysis scripts depend on their outputs in `data/cleaned/`.

| Script | Prediction | Description |
|---|---|---|
| `R-01_data_cleaning.R` | — | Loads GBIF occurrence data; joins site metadata and species traits; harmonizes legacy site codes and species synonyms; calculates trap-day effort; builds the community abundance matrix; runs iNEXT to determine the shared coverage target and generate the coverage-rarefied community matrix. |
| `R-02_precipitation_processing.R` | — | Converts raw NWS daily precipitation (inches) to annual winter totals (mm) with lags WPy0–WPy0-6 for the Montgomery Field regional proxy. Tests whether precipitation variance is primarily temporal or spatial (two-way ANOVA across all stations). Tests for temporal autocorrelation in the annual record (ACF/PACF). Generates precipitation figures and the station map. |
| `R-03_primary_production.R` | 1 | Linear regression of mean summer EVI on same-year winter precipitation (WPy0) across 25 years (2000–2024). Tests whether primary production tracks interannual precipitation variation. |
| `R-04_floral_richness.R` | 1 (supplement) | Mixed-effects model of floral species richness across five survey years (2015, 2016, 2022, 2023, 2024) as a function of site type × year. Also tests EVI as a predictor of floral richness. Emmeans post-hoc contrasts. |
| `R-05_bee_diversity.R` | 2 | **Main diversity analysis.** Coverage-standardized Hill numbers (q = 0, 1, 2) estimated with `iNEXT::estimateD()` at the shared coverage target from R-01. Mixed-effects models with WPy0, WPy0-1, site type, and their interactions. AIC model comparison; marginal and conditional R² via MuMIn. DHARMa and Box-Cox model diagnostics. |
| `R-06_bee_diversity_rarefied.R` | 2 (sensitivity) | Sensitivity analysis repeating the diversity models using rarefaction to the minimum sample size (nmin = 92, 1200 iterations) rather than coverage standardization. Results reported in supplementary materials. |
| `R-07_assemblage_composition.R` | 3 | Hellinger-transformed, effort-normalized RDA with site type, WPy0, and WPy0-1 as predictors. Variance partitioning via partial RDAs. PERMANOVA (adonis2) blocked by plot and by year. Sensitivity analysis with additional precipitation lags. Indicator species analysis (IndVal.g, 1200 permutations) across Reserve/Fragment × Wet/Dry combinations for both same-year and previous-year precipitation windows. Euler diagrams and stacked bar plots of indicator species. |
| `R-08_body_size.R` | 4 | Coverage-standardized abundance-weighted (and presence-weighted) mean ITD as a proxy for assemblage body size. Mixed-effects models with WPy0, WPy0-1, site type, and interactions (main analysis) and without interactions (sensitivity). Type-split models for reserves and fragments separately reported in supplement. DHARMa and Box-Cox model diagnostics. |

### Google Earth Engine

`gee/evi_extraction.js` extracts MODIS MOD13Q1 EVI for natural wildland vegetation in western San Diego County (March–August growing season, 2000–2024) masked to a custom wildlands asset. To run: paste the script into the [GEE Code Editor](https://code.earthengine.google.com/), click **Run**, then go to the Tasks tab and run the export. Save the resulting CSV as `data/raw/wild_evi.csv`.

Wildlands mask asset (public): https://code.earthengine.google.com/?asset=users/jessmullins/Wildlands_mask_sitesBBox

## Model diagnostics

DHARMa simulated residual diagnostics were run for all linear mixed-effects models (R-05 and R-08). For each model, we report: (1) Box-Cox optimal lambda to assess whether transformation is warranted; (2) DHARMa dispersion, outlier, and uniformity tests. All models passed DHARMa tests (p > 0.05), confirming that the Gaussian approximation is acceptable given that diversity and body size values are not concentrated near zero. Full diagnostic plots are saved to `figures/diagnostics/` and summary tables to `results/diagnostics_dharma.xlsx` and `results/diagnostics_dharma_itd.xlsx`.

Type-split body size models (R-08) produce singular random effects fits because splitting by habitat type substantially reduces within-plot replication. Fixed effect estimates remain valid; these results are reported in the supplementary materials.

## R environment

All analyses were run in **R version 4.5.2**. Install all required packages with:

```r
install.packages(c(
  "tidyverse", "lubridate", "lme4", "lmerTest", "car", "iNEXT", "vegan",
  "MuMIn", "performance", "indicspecies", "patchwork", "ggeffects",
  "broom", "broom.mixed", "writexl", "forcats", "readxl", "stringr",
  "emmeans", "openxlsx", "influence.ME", "ggpubr", "ggsignif",
  "geosphere", "ggmap", "ggrepel", "RColorBrewer",
  "eulerr", "DHARMa", "MASS", "ggfittext"
))
```

Key packages and their roles:

| Package | Role |
|---|---|
| `iNEXT` | Coverage-based rarefaction and Hill number estimation |
| `vegan` | RDA, Hellinger transformation, rarefaction |
| `indicspecies` | Indicator species analysis (IndVal.g) |
| `lme4` / `lmerTest` | Linear mixed-effects models |
| `car` | Type III Wald ANOVA |
| `MuMIn` | Marginal and conditional R² |
| `performance` | Model diagnostics |
| `DHARMa` | Simulated residual diagnostics for mixed models |
| `eulerr` | Euler diagrams for indicator species overlap |
| `ggfittext` | Text fitting in variance partition bar plots |
| `ggmap` | Station map (R-02; requires Stadia Maps key) |
